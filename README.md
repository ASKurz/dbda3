

## Package {dbda3}

Welcome to the homepage for the **dbda3** package. This is an **R**
package supporting the third edition of *Doing Bayesian Data Analysis*.
The **dbda3** package provides a variety of convenience functions
supporting Bayesian data analysis, with an emphasis on a
**tidyverse**-oriented workflow, and models fit with the **brms**
package.

## Installation

You can install the **dbda3** package from within **R** by executing

``` r
devtools::install_github("ASKurz/dbda3")
```

Note that the **dbda3** package is not on CRAN, and we do have plans to
make it available on CRAN for the foreseeable future.
